# recr — компактная версия

По умолчанию язык интерфейса определяется по языку Windows. На русском Windows используется русский, на остальных языках — английский. Кнопка с глобусом в настройках сразу переключает язык и запоминает выбор.

By default, recr shows Russian on Russian Windows and English on other Windows display languages. The globe button in Settings switches the language immediately and remembers your choice.

Один `recr.exe` для Windows 10/11 x64. Запись экрана, микрофона и монтаж используют Windows Graphics Capture, WASAPI и Media Foundation. В Windows N могут потребоваться компоненты мультимедиа Windows.

Эта сборка запускается рядом с предыдущей и хранит собственные настройки. По умолчанию она просматривает ту же системную папку записей. Если записывали в другую папку, её можно выбрать в настройках.

**ПКМ по значку в трее** открывает меню записи, библиотеки и настроек. При включённом буфере в меню появляется **Откатить**. **Ctrl + Alt + F9** начинает и останавливает запись. **Ctrl + Alt + F10** сохраняет откат. Горячие клавиши можно изменить.

Флажок **Скрывать рамку захвата** включён по умолчанию. Этот режим использует Desktop Duplication и переключается на резервный захват, если Desktop Duplication недоступен.

Щелчок по уведомлению о сохранении открывает папку с готовым роликом.

Длительность отката вводится в секундах от 1 до 300. Рядом с полем значения от 60 секунд показываются в минутах и секундах. В списке качества указаны расчётное разрешение, частота кадров и целевой битрейт. В окне **Записи** ползунок громкости управляет проигрывателем.

Монтаж сохраняет отдельную копию. Поддержка сторонних форматов зависит от установленных кодеков Windows.

## Сборка

```powershell
cargo build --release --locked
rustc --edition 2024 tools/resources.rs -o target/resources.exe
.\target\resources.exe .\target\release\recr.exe
```
